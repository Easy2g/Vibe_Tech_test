# 🚀 Vibe-Tech: AI 데이터 기반 실시간 강의 중재 솔루션

**Vibe-Tech**는 교수자와 학생 사이의 실시간 소통 장벽을 AI 기술로 허무는 혁신적인 에듀테크 플랫폼입니다. 강의 자료의 정밀 분석부터 실시간 자막, 학생 피드백 기반의 AI 수업 전략 제안까지, 데이터 기반의 스마트한 강의 환경을 제공합니다.

---

## 💡 기획 의도 (Planning Intent)

많은 강의 현장에서 교수자는 학생들의 이해도를 실시간으로 파악하기 어렵고, 학생들은 어려운 용어나 빠른 강의 속도 때문에 흐름을 놓치기 일쑤입니다. **Vibe-Tech**는 이 '간극'을 데이터로 메우기 위해 기획되었습니다.

1.  **AI 맥락 공유**: 강의 자료를 사전 분석하여 학생들에게 학습 목표와 핵심 키워드를 미리 공유합니다.
2.  **실시간 이해도 시각화**: 학생들의 '이해 어려움' 신호와 '단어 클릭' 데이터를 교수자에게 대시보드로 즉시 시각화합니다.
3.  **AI 중재(Mediation)**: AI가 강의 내용과 학생 반응을 실시간으로 교차 분석하여, 교수자에게 "지금 이 개념을 다시 설명하세요"와 같은 구체적인 수업 전략을 제안합니다.
4.  **지속 가능한 연결**: 교수-학생 구독 시스템을 통해 일회성 세션이 아닌, 지속적인 학습 커뮤니티를 형성합니다.

---

## ✨ 핵심 기능 (Core Features)

### 👨‍🏫 교수자용 (Teacher Dashboard)
-   **아이디 기반 회원가입 및 4자리 고유 교수코드 발급**: 학생이 자신을 구독할 수 있는 고유 식별자 제공.
-   **무제한 PDF/TXT 강의 자료 분석**: 전체 페이지 스마트 샘플링(페이지당 300자) 및 저해상도 Vision 폴백을 통해 토큰 효율을 극대화하면서 정밀한 요약 제공.
-   **실시간 STT(Speech-to-Text) 자막**: 교수자의 음성을 실시간으로 텍스트화하여 모든 학생에게 동기화 전송.
-   **AI 스마트 인사이트**: 학생들의 피드백(속도, 미이해 신호)을 분석하여 실시간 수업 전략 제안.

### 👨‍🎓 학생용 (Student View)
-   **교수 구독 시스템**: 교수코드를 입력하여 선호하는 교수님을 등록하고, 강의 시작 시 실시간 알림/목록 확인.
-   **맥락 기반 단어 사전**: 자막 중 모르는 단어를 클릭하면 AI가 현재 강의 주제에 맞춰 쉬운 설명을 제공.
-   **실시간 피드백 송신**: '설명이 어려워요', '강의 속도(빠름/적당/느림)' 신호를 익명으로 즉시 전달.
-   **AI 강의 요약 패널**: AI가 분석한 오늘의 주제, 핵심 키워드, 학습 요약을 상시 확인.

## 🛠 기술 스택 (Tech Stack)

-   **Frontend**: Vite, React 19, Tailwind CSS v4, Framer Motion
-   **Backend/DB**: Firebase Realtime Database
-   **AI/Vision**: Gemini 2.5 Flash Lite API (Multimodal - Text & Vision)
-   **PDF Engine**: PDF.js (Client-side extraction & rendering)

## 📖 상세 사용법 (User Guide)

### 1단계: 교수자 세션 준비
1.  교수 포털에서 **회원가입**을 진행합니다. (아이디, 이름, 비밀번호 설정)
2.  로그인 후 상단에 표시된 **4자리 교수코드(예: AB12)**를 확인하고 학생들에게 공유합니다.
3.  강의 자료(PDF/TXT)를 업로드합니다. AI가 자동으로 전체 맥락을 분석합니다.
4.  **[실시간 강의 세션 열기]** 버튼을 클릭하여 강의를 시작합니다.

### 2단계: 학생 입장 및 구독
1.  학생용 화면에서 **[교수 등록하기]**를 클릭합니다.
2.  공유받은 **교수코드 4자리**를 입력하여 교수님을 등록합니다.
3.  등록된 교수님이 강의를 시작하면 **[강의 참여]** 목록에 해당 강의가 자동으로 표시됩니다.
4.  강의를 클릭하여 입장합니다.

### 3단계: 실시간 강의 진행
-   **학생**: 실시간 자막을 보며 어려운 단어는 클릭해 설명을 듣고, 이해가 안 되면 하단의 신호를 보냅니다.
-   **교수**: 대시보드에서 학생들의 피드백 데이터와 키워드 히트맵을 모니터링합니다. 
-   **AI**: 데이터가 쌓이면 대시보드 우측 하단에 **[AI 스마트 인사이트]**가 활성화되어 교수님께 수업 조언을 드립니다.
